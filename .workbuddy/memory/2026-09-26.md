**体检发现（实证，非推测）**

- 站点 `https://tool.mmzhiku.xyz` 为纯 CSR SPA，`dist/` 仅 1 个 `index.html`。
  `curl /hash-text` 原始 HTML 返回的 `<title>`/`description` 是**首页的** → 56 个工具页对爬虫标题重复、正文空白。这是自然流量不足的头号根因。
- 全站无 JSON-LD（`grep application/ld+json` 仅命中 meta-tag-generator 的单测字符串）。
- i18n 语言切换只改 localStorage（`modules/i18n/index.ts` 的 `changeLocale`），无 `/en/` 路由；`index.html` 硬编码 `lang="zh-CN"` → 英文版不可收录、无法用 hreflang。
- `src/modules/seo/document-meta.tsx` 缺 canonical / og:url / og:image / twitter:card / robots / hreflang。
- `public/sitemap.xml` 是被 git 跟踪的生成物且陈旧：注册 56 工具、收录 52；缺 `docker-memo`、`maven-memo`、`nvm-memo`、`image-stack`；54 条 lastmod 全为同一构建日（2026-09-24），无 changefreq/priority。
- `public/fonts/` 约 111 MB 中文字体（NotoSansSC 16.5MB×3、SourceHanSerifSC 11.7MB×3、AlibabaPuHuiTi 8.5MB×2、MiSans 8MB×2）。**仅被 resume 与 music-to-video 引用**，不影响首页 LCP，但这两个工具会拉 8–17MB 单文件。
- `router.tsx` 有 `/resume/:id` 独立路由（编辑器），未 noindex、robots 未收敛。
- 托管：EdgeOne makers；HTML `Cache-Control: public,max-age=0,must-revalidate`。

**关键结论（外部依据已核验）**

- AI 爬虫（ChatGPT/Perplexity/Gemini）绝大多数不执行 JS → 纯 CSR 站点在 AI 搜索渠道完全不可见，这是 2026 年新增的增长最快渠道。
- 百度抓取/渲染分离，CSR 渲染排期数小时至数天。
- 对该站（静态固定 56 路由、内容不随请求变化）**最优解是构建期预渲染（SSG 语义）**，而非迁 Next.js/Vike。推荐 Puppeteer 构建后预渲染脚本，零业务代码改动，且能自动把运行时注入的 DocumentMeta 烘进静态 HTML。
