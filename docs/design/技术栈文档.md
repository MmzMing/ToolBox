## 2. 选型理由

- **Vite 8**：rolldown 内核构建极快（本项目全量构建 < 1s），原生 ESM、按工具目录自动代码分割。
- **React 19**：原生支持 `<title>`/`<meta>` 提升到 `<head>`，SEO 元信息无需 helmet 类库；
  `use()`/Actions 等新能力为后续迭代留余地。
- **shadcn/ui**：组件源码直接进仓库（`src/components/ui/`），可完全定制且不背组件库体积；
  Tailwind v4 + oklch CSS 变量令牌天然支持亮暗主题。
- **react-router v8**：v7→v8 破坏性变更极小（官方声明），data 模式 `createBrowserRouter`
  与"工具注册表即路由表"的架构契合。
- **zustand**：shadcn 生态事实标准；`persist` 中间件 + 自定义 `merge` 实现 localStorage
  读取归一化校验（防止脏数据）。
- **i18next**：命名空间按文件拆分（每分类一个 `tools-*.json`），多语言包惰性加载 + 后台预载。
- **fuse.js**：纯前端模糊搜索，权重配置（标题 2 / 跨语言标题 1.5 / 关键词 1 / 描述 0.5）。
- **Vitest**：与 Vite 共享转换管线，零额外配置成本；只测 service 纯函数（见测试策略）。

## 3. TypeScript 配置要点

`tsconfig.app.json` 关键项：

- `strict: true`、`noUnusedLocals`、`noUnusedParameters`、`noFallthroughCasesInSwitch`
- `verbatimModuleSyntax`：仅类型导入必须 `import type`
- `erasableSyntaxOnly`：禁止 enum / namespace / 参数属性
- `moduleResolution: bundler` + 路径别名 `@/* -> src/*`
- `esModuleInterop` + `resolveJsonModule`（CJS 依赖与 i18n JSON 语言包）

## 5. 质量门禁

提交前四道闸门（全部通过才算完成）：

```bash
pnpm lint        # eslint . --max-warnings 0
pnpm typecheck   # tsc -b
pnpm test        # i18n 重复键检查 + vitest run
pnpm build       # prebuild(拷贝 WASM 编解码器) + tsc -b + vite build + postbuild(sitemap)
```

> 测试前会先运行 `scripts/check-i18n-duplicate-keys.mjs`，拦截语言包 JSON 中
> 同层重复键（此类错误会被 JSON.parse 静默吞掉，曾导致工具标题显示错误）。
