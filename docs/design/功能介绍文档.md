# 功能介绍文档

> ToolBox 全部功能与 86 个工具清单。全部工具在浏览器本地运行，数据不上传。

## 1. 站点级功能

| 功能 | 说明 |
| --- | --- |
| 工具箱导航 | 左侧手风琴分类导航（10 类），含收藏夹与最近使用置顶分组；手机端为抽屉 |
| 全局搜索 | Ctrl/Cmd+K 命令面板，中英跨语言模糊搜索（名称/描述/关键词），键盘导航 |
| 收藏工具 | 工具页星标收藏，首页拖拽排序，localStorage 持久化 |
| 常用工具 | 自动记录最近使用（次数+时间），侧栏与首页展示 Top 8 |
| 主题切换 | 浅色 / 深色 / 跟随系统 |
| 语言切换 | 简体中文 / English，跟随浏览器首访协商，持久化记忆 |
| 站点地图 | 构建时生成 sitemap.xml + robots.txt，全站 URL 可被发现 |
| 响应式 | 手机 / 平板 / PC 三档断点全适配 |
| 隐私 | 纯前端本地计算，无后端、无上传、无追踪 |
